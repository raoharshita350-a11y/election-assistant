# AI Studio Testing (Implementation Evidence)
This project was tested using Google AI studioo to simulate real conversational behavior of the Election Guide Assistant.
Platform used:
- Google AI Studio (Gemini-based prompting environment)

## What was tested
The system prompt was used to evaluate:
- User intent detection
- Step-by-step guidance flow to make user understand
- Eligibility checks: if they can/can't vote
- Registration guidance, if needed
- Voting process explanation

## Sample Behavior Observed
When user asked:
- “I want to vote”
→ Assistant asked about registration status

- “I am not registered”
→ Assistant guided registration steps

- “How do elections work?”
→ Assistant explained structured phases (registration, campaigning, voting, counting)

## Outcome
The assistant successfully:
- Adapted responses based on user input
- Maintained structured flow
- Provided simplified civic education
- Followed prompt constraints effectively
- Provided a final step to take action

##  Conclusion
Google AI Studio was used as a testing environment to validate the prompt design and conversational flow of the Election Guide Assistant.
